# File Server

Проект на Go для работы с документами и файлами.

## Переменные окружения

Перед запуском убедитесь, что в корне проекта создан файл `.env` с настройками подключения к базе данных (`DB_USER`, `DB_PASSWORD`, `DB_NAME` и др.). Пример со всеми переменными - .env.example

## Команды Makefile

Для управления проектом используйте `make <команда>`:

### Окружение (Docker)

* `make deps-up` — поднять инфраструктуру (PostgreSQL и зависимые сервисы) в фоновом режиме.
* `make deps-down` — остановить и удалить контейнеры инфраструктуры.

### Миграции базы данных

* `make migrate` — применить все непримененные миграции БД.
* `make migrate-down` — откатить последнюю примененную миграцию.

### Запуск приложения

* `make start` — запустить Go-сервер локально.
